# Click Counter Frontend

React frontend application for the Click Counter App.

## Development

```bash
npm install
npm run dev
```

The application will be available at `http://localhost:5173`.

## Build

```bash
npm run build
```

The built files will be in the `dist/` directory.

## Features

- User authentication (login/register)
- Click counter dashboard
- Analytics page with user and global statistics
- Responsive design with Tailwind CSS

## Technology Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- React Router
- Axios
- Recharts

## Environment Variables

Create a `.env` file:

```env
VITE_API_URL=http://localhost:5000
```
